📊 DATABASE ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

GET /api/admin/database/info
├─ Returns database location, size, tables, and record counts
└─ Example: {"database_path": "...", "file_size_mb": 0.03, "tables": [...]}

GET /api/admin/database/tables
├─ Returns list of all table names
└─ Example: {"tables": ["users", "analyses"]}

GET /api/admin/database/table/<table_name>
├─ Returns all records from specified table
└─ Example: {"table": "users", "columns": [...], "rows": [...]}

GET /api/admin/database/table/<table_name>/schema
├─ Returns table structure (columns, types, keys)
└─ Example: {"table": "users", "schema": [{...}, {...}]}

All endpoints protected with @admin_required decorator ✅
